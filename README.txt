GRUPO DE DESARROLLO URBANO S.A. — SITIO V9 OPTIMIZADO PARA MÓVIL

MEJORAS DE RENDIMIENTO
- Se redujo la presentación corporativa PDF de aproximadamente 37 MB a aproximadamente 3 MB, conservando buena calidad visual.
- La portada mantiene 4 imágenes y rota cada 5 segundos.
- La primera imagen de portada se carga con prioridad; las siguientes se difieren para no competir con la carga inicial.
- Se generaron versiones móviles de las fotografías para teléfonos.
- El portafolio y la galería usan miniaturas livianas; la imagen grande solo se carga al abrir un proyecto.
- Se optimizaron los logos usados en encabezado y pie de página.
- En teléfonos se reducen efectos gráficos costosos como blur, sombras y animaciones intensas.
- Se agregaron reglas de caché para Netlify mediante netlify.toml.
- Se mantiene toda la estructura, textos, formulario, redes sociales, WhatsApp, Google Maps y Waze.
